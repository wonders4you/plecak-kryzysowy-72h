# Czego NIE pakować

Tytuł brzmi prowokacyjnie, ale w plecaku awaryjnym **mniej znaczy więcej**. Poniżej lista rzeczy, które często lądują w plecakach, a które:

- są niepotrzebnie ciężkie,
- nie mają zastosowania w 72h,
- tworzą fałszywe poczucie bezpieczeństwa,
- mogą być niebezpieczne.

## 1. Ciężkie / zbędne

| Nie pakuj                          | Dlaczego                                    | Zamiast tego                              |
|------------------------------------|---------------------------------------------|-------------------------------------------|
| 6 L wody w plecaku                 | 6 kg, nie do noszenia                       | 2 L + tabletki / filtr                    |
| Słoje szklane z jedzeniem          | Tłuką się, ciężkie                          | Konserwy w puszce / liofilizaty           |
| Pełne butelki szamponu (250 ml)    | Za dużo na 72h                              | Travel-size / mydło w kostce              |
| Zestaw 10 narzędzi                 | Waga, duplikaty                             | Multitool                                 |
| Śpiwór zimowy latem                | 1 kg zbędnie                               | Koc NRC + polar                           |
| Karimata gruba na krótką ewakuację | Objętość                                    | Karimata cienka / koc NRC                 |
| 3 latarki                          | 2 wystarczą (1 czołówka + 1 zapasowa)       | 1 czołówka + 1 mała zapasowa              |
| Apteczka „na każdą chorobę”        | Waga, przeterminowanie                      | Leki podstawowe + osobiste                |

## 2. Niepraktyczne w 72h

| Nie pakuj                          | Dlaczego                                    |
|------------------------------------|---------------------------------------------|
| Namiot ekspedycyjny 4-osobowy      | Zbyt ciężki, ewakuacja trwa krótko          |
| Łóżko polowe                       | Ciężar, karimata wystarczy                  |
| Książka „przetrwanie w dziczy 500 s.” | W stresie nie czytasz; laminowana instrukcja wystarczy |
| Skomplikowane zestawy do łowienia   | W 72h nie łowisz, masz racje                |
| Sprzęt do wspinaczki               | Jeśli nie jesteś w górach                   |
| Łaźnia polowa / prysznic           | Wystarczą chusteczki nawilżane              |
| Generator prądu                    | Ciężar, hałas, paliwo                       |
| Wielka apteka domowa               | Wystarczy apteczka urazowa + leki osobiste  |

## 3. Fałszywe poczucie bezpieczeństwa

| Nie pakuj                          | Dlaczego                                    |
|------------------------------------|---------------------------------------------|
| Broń / amunicja (w PL nielegalne bez pozwolenia) | Prawo, eskalacja, niepotrzebne ryzyko |
| Tarcza / hełm taktyczny            | W realnej ewakuacji niepotrzebne            |
| Maski gazowe wojsowe               | Przeterminowane filtry, nie pasują, ciężkie; FFP3 lepsze na dym/pył |
| „Tabletki antyradiacyjne” bez wskazań | Bez szkolenia i wskazań szkodliwe         |
| Magiczne „zioła na wszystko”       | Nie zastąpią leków i wody                   |
| Noże bojowe / miecze               | Multitool wystarczy; broń przyciąga uwagę   |
| Kamizelki taktyczne z 20 kieszeniami | Waga, krzykliwy wygląd                    |

## 4. Niebezpieczne

| Nie pakuj                          | Dlaczego                                    |
|------------------------------------|---------------------------------------------|
| Kuchenka gazowa do ogrzewania pomieszczenia | Tlenek węgla – śmiertelne          |
| Świece w łatwopalnych opakowaniach | Pożar                                       |
| Lejek do benzyny + zapalniczka razem | Pożar / wybuch                            |
| Leki bez ulotek i dat              | Trucizna po terminie                        |
| Zużyte baterie wymieszane z nowymi | Wyciek, uszkodzenie sprzętu                 |
| Łatwopalne płyny w szklanych butelkach | Tłuczenie się, pożar                    |
| Środek owadobójczy obok jedzenia   | Skażenie żywności                           |
| Powerbank bez obudowy / uszkodzony  | Pożar (li-ion)                              |

## 5. Krzykliwe / przyciągające uwagę

W ewakuacji miejskiej chcesz wyglądać jak „zwykły człowiek z plecakiem”, nie jak „taktyczny survivalowiec”:

- militarny camo (lepiej czarny / granatowy / oliwkowy),
- plecak z napisem „TACTICAL / PREPPER”,
- naszywki z czaszkami / nożami,
- jaskrawe kolory (chyba że ewakuacja w lesie / górach – wtedy odblaski są pożądane).

## 6. Przeterminowane / bez rotacji

Wszystko, co ma datę, **będzie przeterminowane** bez przeglądu:

- leki,
- racje żywnościowe,
- woda (butelkowa – po 6–12 miesiącach smak plastiku),
- baterie (samorozładowanie),
- tabletki do uzdatniania wody,
- chusteczki nawilżane (wysychają),
- apteczka (plastry tracą kleistość, gaza wilgnie).

**Rozwiązanie:** przegląd co 6 miesięcy + rotacja jedzenia (FIFO).

## 7. Duplikaty zbędne

2 noże tak, 3 noże nie. 2 źródła ognia tak, 5 zapalniczek nie. 2 latarki tak, 4 nie. Każdy duplikat to waga i objętość.

## Podsumowanie

Plecak kryzysowy (ewakuacyjny, survivalowy, przetrwania) to **nie** lista „wszystkiego, co może się przydać”. To zestaw rzeczy, które **na pewno** będą potrzebne w 72h i które **unesiesz**. Jeśli masz wątpliwości, czy coś spakować – prawdopodobnie nie pakuj.
