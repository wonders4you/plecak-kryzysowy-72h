# Poziomy przygotowania

Nie każdy potrzebuje pełnego plecaka 72h. Poniżej 3 poziomy – wybierz ten, który pasuje do Twojej sytuacji, klimatu i budżetu. Możesz rozbudowywać poziom wyżej w miarę możliwości.

## Poziom 1 – Minimum („na wszelki wypadek”)

**Cel:** przetrwać 12–24h ewakuacji (korek, blackout, nagła ewakuacja z domu do rodziny/hotelu).

**Waga:** ~3–5 kg
**Pojemność plecaka:** 20–30 L

### Co zawiera
- Woda 1 L + tabletki do uzdatniania
- Batoniki / kanapki na 1 dzień
- Apteczka podstawowa + koc NRC
- Latarka czołówka + baterie
- Powerbank + kabel
- Dokumenty (ksero) + gotówka
- Telefon z numerami ICE
- Małe radio na baterie
- Papier toaletny, żel antybakteryjny
- Poncho / kurtka przeciwdeszczowa

### Dla kogo
- Mieszkaniec miasta, krótkie dojazdy.
- Plecak w bagażniku auta.
- Osoba z ograniczonym budżetem.

## Poziom 2 – Standard (72h dla 1 osoby)

**Cel:** przetrwać 72h ewakuacji samodzielnie (powódź, pożar, długi blackout, ewakuacja do schronienia).

**Waga:** ~7–10 kg
**Pojemność plecaka:** 30–45 L

### Co zawiera (na bazie poziomu 1)
- Woda 2–3 L + filtr słomkowy + tabletki
- Racje 72h (puszki + liofilizaty + batony)
- Kuchenka + kartusz + kubek
- Apteczka rozszerzona + tourniquet
- Śpiwór / koc gruby + karimata (zima)
- Multitool + taśma naprawcza + paracord
- Radio na baterie + zapas baterii
- Powerbank 10 000 mAh
- Pełen zestaw higieny
- Mapa papierowa + notes + ołówek
- Czapka, rękawiczki, skarpety zapasowe

### Dla kogo
- Domownik w regionie narażonym (powodzie, wichury).
- Rodzic, który musi zaopiekować się sobą i dzieckiem.
- Sensowny kompromis wagi / możliwości.

## Poziom 3 – Rodzina / Długotrwały (72h dla 2–4 osób)

**Cel:** przetrwać 72h z rodziną, w tym z dziećmi / osobami starszymi / zwierzętami.

**Waga:** ~15–25 kg (rozłożone na 2 plecaki)
**Pojemność:** 2 × 40–60 L + małe plecaczki dla dzieci

### Co zawiera (na bazie poziomu 2, × liczba osób)
- Woda 2 L/os + filtr gravity + tabletki
- Racje 72h × liczba osób + zapas
- Kuchenka większa + 2 kartusze
- Apteczka rodzinna (z lekami dzieci, kobietami, seniorami)
- Namiot / tarp + karimaty
- Śpiwory / koce dla wszystkich
- Radio PMR (komunikacja wewnątrz rodziny)
- Powerbank 20 000 mAh + panel solarny
- Dokumenty wszystkich + ksero + pendrive ze skanami
- Pieluchy / leki specjalistyczne / aparat słuchowy baterie
- Jedzenie i woda dla zwierząt (jeśli są)
- Wózek / nosidło dla małego dziecka

### Dla kogo
- Rodziny w regionach o podwyższonym ryzyku.
- Gospodarstwa z dziećmi / seniorami / zwierzętami.
- Osoby, które mogą i chcą nosić więcej.

## Jak wybrać poziom

| Kryterium                          | Sugerowany poziom |
|------------------------------------|-------------------|
| Mieszkasz w mieście, krótkie trasy | 1                 |
| Region powodzi / wichury / las     | 2                 |
| Rodzina z dziećmi / seniorami      | 3                 |
| Plecak do auta na korki            | 1 (lub 2 zimą)    |
| Ograniczona siła / zdrowie         | 1, ale rozbuduj apteczkę |

## Ewolucja poziomów

- Zacznij od **poziomu 1** – zbuduj go w weekend.
- Co miesiąc dokładj jeden element z poziomu 2.
- Po 6–12 miesiącach masz pełny poziom 2.
- Poziom 3 buduj, gdy pojawi się rodzina / zmiana regionu.
