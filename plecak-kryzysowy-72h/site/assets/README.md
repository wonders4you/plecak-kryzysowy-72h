# Katalog na zasoby statyczne (obrazy, ikony, fonty).

W tej wersji nie są używane żadne zewnętrzne zasoby – strona działa offline bez pobierania czegokolwiek z sieci (systemowe emoji i fonty).

Jeśli w przyszłości dodasz logo, ikony lub fonty, umieść je tutaj i odwołuj się przez `assets/...` w `index.html` / `style.css`.
